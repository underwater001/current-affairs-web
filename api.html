Data API

Read-only JSON · version 1 · no key needed

WebQuizSourcesAPIGitHub

Everything on the web is published as plain JSON files, so any app can use it: a quiz app, flashcards, a revision planner, a Telegram bot, a spreadsheet. The files are rebuilt every time a paper is added. Any website or app can read them directly from the browser.

Quick start

Base URL:

https://underwater001.github.io/current-affairs-web/api/v1/

JavaScript

const BASE = 'https://underwater001.github.io/current-affairs-web/api/v1/';
const index = await (await fetch(BASE + 'index.json')).json();
// all facts, month by month
const months = await Promise.all(index.months.map(m => fetch(BASE + `facts/${m}.json`).then(r => r.json())));
const facts = months.flatMap(m => m.facts);
const cgl = facts.filter(f => f.tags.includes('CGL'));

Python

import requests
BASE = "https://underwater001.github.io/current-affairs-web/api/v1/"
index = requests.get(BASE + "index.json").json()
facts = [f for m in index["months"] for f in requests.get(f"{BASE}facts/{m}.json").json()["facts"]]
economy = requests.get(BASE + "nodes/economy.json").json()["facts"]   # a subject and all its branches

Command line

curl -s https://underwater001.github.io/current-affairs-web/api/v1/latest.json

Endpoints

PathReturns
index.jsonStart here: totals, the list of months that have facts, last update date, and this endpoint list.
papers.jsonPublications and every paper read: date, edition, pages, Drive link, fact counts.
nodes.jsonThe whole topic tree: 12 subjects (junctions) and their branches, with links, children and fact counts.
facts/{YYYY-MM}.jsonEvery fact from one month, e.g. facts/2026-11.json.
papers/{paper_id}.jsonOne paper and its facts, e.g. papers/2026-11-02.json.
nodes/{node_id}.jsonOne topic and every fact filed on it or its sub-branches, newest first, e.g. nodes/elections-sir.json.
latest.jsonThe most recent date's papers and facts.
quizzes/index.jsonEvery quiz date, newest first, with question counts (total, CGL, UPSC, high priority).
quizzes/{YYYY-MM-DD}.jsonOne date's quiz, e.g. quizzes/2026-11-03.json. Each question carries its options, answer index, explanation and the tested fact's tags, priority, GS paper, topic and source.

Spreadsheets of the same data: exports/facts.csv, exports/nodes.csv, exports/papers.csv, exports/quiz.csv.

Objects

Fact

FieldTypeMeaning
idstringPermanent id, f<YYYYMMDD>-<NNN>. Never reused or renumbered, so it is safe to store (e.g. for quiz progress).
dateYYYY-MM-DDDate of the paper.
paper, source, linkstringPaper id, publication short name, and link to the original (or null).
pagestring | nullPage(s) in the paper, e.g. "1,10", "II".

plainstringThe same text without formatting marks.
keysstring[]The bold terms. Ready-made answers for fill-in-the-blank and MCQ generation.

Quiz question

id (qYYYYMMDD-NNN, permanent), date, type (mcq, statements, assertion), q, options, answer (0-based index), explanation, and from the tested fact: fact, fact_date, tags, priority, gs, node, node_label, junction, source, page, link, fact_text. The same questions are in exports/quiz.csv.

Node (topic)

FieldMeaning
id, label, short, summaryIdentity and description. short is set for subjects only.
parent, junction, path, depth, childrenPosition in the tree. Subjects have parent: "hub" and depth 1.
linksRelated topics, usually in other subjects.
facts_own, facts_total, first_date, last_dateFacts filed directly on it, including sub-branches, and the date range they span.
created, order, hueFirst appearance, display order, and subject colour (0–359, OKLCH hue).

Paper

id, date, publication, name, short, edition, pages, link, added, and counts facts, cgl, upsc, background, nodes_used.

Rules you can rely on

  • Stable ids. Fact, node and paper ids never change meaning. A corrected fact keeps its id.
  • Additive changes only in v1. New fields may appear; existing fields are not renamed or removed. A breaking change would ship as /api/v2/ alongside v1.
  • Cross-origin reads work. GitHub Pages serves these files with open CORS, so a browser app on any domain can fetch them.
  • Freshness. Files update a minute or two after each paper is pushed; GitHub's cache can add up to ~10 minutes. Check index.json → updated.
  • Read-only. To add or fix data, change the files in data/ and run python3 tools/build.py; never edit api/ by hand.

Facts are short summaries for exam revision, with the source and page for checking. The newspapers themselves remain their publishers' copyright and are not republished here.
